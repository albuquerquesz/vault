# PRD: Aumento de Detalhamento do `OrderSourceMixChart`

## 1. Objetivo
Evoluir o componente `OrderSourceMixChart` para exibir informações mais acionáveis por linha, incluindo valor monetário, categoria, porcentagem sobre o patrimônio geral e indicador visual de desempenho vs mês anterior.

## 2. Escopo
- Em escopo:
  - Ajustes de UI e estrutura de dados do `OrderSourceMixChart`.
  - Exibição de dados detalhados por linha.
  - Adição de `border-bottom` separando cada linha.
- Fora de escopo:
  - Mudanças de backend/API.
  - Alterações em outros gráficos do dashboard.

## 3. Requisitos Funcionais

### 3.1 Dados por linha
Cada linha da lista do `OrderSourceMixChart` deve mostrar:
- `categoria` (nome da origem/categoria)
- `valor` (formatado em moeda)
- `porcentagem` baseada no patrimônio geral
- `ícone de tendência` indicando se o resultado está melhor ou pior que o mês passado

### 3.2 Cálculo da porcentagem
- A porcentagem exibida na linha deve representar:
  - `valor_da_categoria / patrimonio_geral * 100`
- O patrimônio geral deve ser fornecido ao componente por prop explícita.
- Quando patrimônio geral for `0` ou inválido, a porcentagem deve exibir `0%` e evitar divisão por zero.

### 3.3 Indicador de tendência vs mês passado
- Cada linha deve receber um estado comparativo do mês anterior.
- Estados mínimos:
  - melhor que mês passado
  - pior que mês passado
  - neutro/sem variação (opcional, mas recomendado)
- O ícone deve comunicar o estado com semântica visual clara (direção/cor).

### 3.4 Separação visual entre linhas
- Adicionar `border-bottom` entre todas as linhas da listagem.
- A última linha não deve parecer colada ao container; manter espaçamento vertical consistente.

## 4. Requisitos de Interface/Tipos
- Evoluir `OrderSourceDatum` para incluir os novos campos necessários para renderização:
  - `category` (ou reaproveitar `source` como categoria)
  - `amount`
  - `monthOverMonthTrend` (enum/string union para `up | down | neutral`)
- Adicionar prop obrigatória `totalNetWorth` (patrimônio geral) no componente.
- Manter compatibilidade visual do card (gráfico + lista), alterando apenas o nível de detalhe e layout interno da lista.

## 5. UX e Visual
- A lista deve seguir leitura da esquerda para direita:
  - marcador/ícone da categoria
  - nome da categoria
  - porcentagem
  - valor
  - ícone de tendência
- A hierarquia textual deve priorizar categoria e valor.
- A borda entre linhas deve ser sutil e alinhada com tokens do tema (`border`/`muted`).

## 6. Critérios de Aceitação
- O `OrderSourceMixChart` exibe por linha: categoria, valor, porcentagem do patrimônio e ícone de tendência.
- A porcentagem é calculada corretamente com base no patrimônio geral.
- Existe `border-bottom` entre as linhas.
- Estados de tendência (melhor/pior, e neutro se adotado) aparecem visualmente distintos.
- O layout permanece responsivo e sem quebra de alinhamento em desktop e mobile.
- Não há regressão de tema claro/escuro no componente.
