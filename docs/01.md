# PRD: Personal Financial Stability Dashboard

## 1. Objective
Build a lightweight financial dashboard that helps users track monthly spending against income, add new expenses quickly, and follow a safe daily spending cap to remain financially stable until month-end.

## 2. Core Features

### 2.1 Expense List
- Show a chronological list of all expenses for the selected month.
- Each expense must include:
  - Date
  - Amount
  - Category
  - Optional note
- Allow basic filtering by category and date range within the month.

### 2.2 Add New Expense
- Provide a fast form to register a new expense.
- Required fields:
  - Date
  - Amount (> 0)
  - Category
- Optional field:
  - Note
- New expense must appear immediately in the list and update all metrics.

### 2.3 Monthly Spend Percentage (vs Salary)
- User inputs monthly salary (income for the month).
- System calculates and displays:
  - Total spent in month
  - Percentage spent of salary
- Formula:
  - `spent_percentage = (total_spent / monthly_salary) * 100`

### 2.4 Stable Daily Spending Goal
- Define a daily maximum spend based on remaining money and remaining days in the month.
- System calculates and displays:
  - Remaining budget: `monthly_salary - total_spent`
  - Remaining days (including current day)
  - Daily spending cap: `remaining_budget / remaining_days`
- This value is the recommended maximum amount the user can spend per day while staying stable through month-end.

## 3. Functional Requirements
- Recalculate all indicators in real time whenever:
  - Salary is changed
  - A new expense is added
  - Month selection changes
- Prevent invalid states:
  - Salary must be > 0
  - Expense amount must be > 0
  - If remaining budget <= 0, daily cap must be `0` and show overspent state.

## 4. Non-Functional Requirements
- Responsive UI (mobile + desktop).
- Currency formatting aligned with user locale.
- Feedback states for empty list, loading, and validation errors.

## 5. Success Criteria
- User can add and view expenses for the current month.
- User can clearly see how much of salary has been spent.
- User receives a daily spending cap that updates accurately and helps maintain end-of-month stability.
